What this tab is for

The Mailbox tab runs the assistant once, the way you set the switches, so you can watch one attack happen. This tab answers a different question: would each defense have changed the outcome?

It runs one trial from the research corpus a single time, with both defenses watching but not interfering, then scores that one run four ways — no defense, detection only, prevention only, both. Because all four come from the same execution, any difference between them is the defense, not luck.

Use it when you have changed detection.py or prevention.py and want to see whether your arm pulls away from A. Numbers for the report come from make eval, never from here.
